◆ module_loader_load_program()

char * module_loader_load_program ( char const *  entryPath)

Loads a module graph starting from the specified entry path.

Resolves and validates import and export declarations and returns a single source text that can be compiled by the existing compiler frontend.

Parameters
entryPathPath to the entry module.
Returns
Heap-allocated source text or NULL if loading failed.
